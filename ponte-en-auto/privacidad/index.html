Política de privacidad

Ponte en Auto · Aplicación de gestión y publicación de contenidos.

Responsable

Ponte en Auto es una herramienta privada administrada por Emilio Ponte. Contacto: ponteenauto@gmail.com.

Uso de datos de Google y YouTube

La aplicación utiliza la API de YouTube y OAuth 2.0 de Google únicamente para acceder a la cuenta autorizada por su propietario, consultar información necesaria del canal y publicar y gestionar contenidos solicitados por el propio usuario.

La aplicación no vende datos personales ni comparte datos obtenidos mediante las APIs de Google con terceros con fines publicitarios.

Conservación y seguridad

Las credenciales OAuth se almacenan de forma privada en el sistema controlado por el responsable y se utilizan exclusivamente para mantener la automatización autorizada. El acceso puede revocarse desde la configuración de seguridad de la cuenta de Google.

Derechos y contacto

Para consultas sobre privacidad, acceso o eliminación de datos relacionados con Ponte en Auto, escribe a ponteenauto@gmail.com.

El uso de información recibida de las APIs de Google se ajusta a la política de datos de usuario de los servicios API de Google, incluidos sus requisitos de uso limitado.
